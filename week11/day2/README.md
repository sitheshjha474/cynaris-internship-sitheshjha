# Executive Reports — Plotly + Python-pptx

## Objective
Build an automated executive reporting system using Python.
The project analyzes sales performance, creates interactive charts,
and generates a PowerPoint presentation for business stakeholders.

## Technologies
- Python
- Pandas
- NumPy
- Plotly
- Kaleido
- python-pptx

## Workflow
1. Generate a sample retail sales dataset.
2. Calculate sales KPIs.
3. Analyze monthly, regional, and product performance.
4. Create interactive Plotly visualizations.
5. Export charts as PNG images.
6. Generate a PowerPoint executive report.
7. Save the report and KPI summary.

## PowerPoint Contents
- Executive summary
- Key performance indicators
- Monthly sales trend
- Regional sales performance
- Product sales contribution
- Key business findings
- Recommendations
- Conclusion

## Run Instructions

Install dependencies:

    python -m pip install -r requirements.txt

Run the application:

    python executive_report.py

## Output
All generated files are stored in the outputs folder.

## Learning Outcomes
- Automating business reports using Python
- Creating interactive visualizations with Plotly
- Exporting charts for presentations
- Generating PowerPoint reports using python-pptx
- Communicating business findings and recommendations

## Limitation
The project uses synthetic sales data for demonstration.
The results do not represent actual company performance.
