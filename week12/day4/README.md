

## Overview

This repository contains practical projects completed during Week 10
of the data analytics internship.

The work covers forecasting, anomaly detection, data storytelling,
executive reporting, production architecture, and security auditing.

## Projects Completed

| No. | Project | Main Technologies |
|---|---|---|
| 1 | Time Series Analysis | Python, Pandas, Statsmodels |
| 2 | Indian Market Forecasting | Prophet, yfinance, Pandas |
| 3 | Anomaly Detection | Isolation Forest, Scikit-learn |
| 4 | Data Storytelling | Pandas, Matplotlib |
| 5 | Executive Reporting | Plotly, python-pptx |
| 6 | Production Architecture Review | Python, Markdown, Mermaid |
| 7 | Data Platform Security Audit | Python, Regular Expressions |

## Project Details

### 1. Time Series Analysis
- Analyzed monthly sales trends.
- Examined trend and seasonality.
- Applied statistical forecasting techniques.
- Evaluated forecasts using MAE and RMSE.

### 2. Indian Market Forecasting
- Retrieved NIFTY 50 historical market data.
- Prepared data for Prophet.
- Evaluated forecasts using a chronological holdout set.
- Generated future forecast visualizations.

### 3. Anomaly Detection
- Generated a sample sales dataset.
- Applied Z-score and IQR statistical methods.
- Applied Isolation Forest.
- Compared anomaly detection results.

### 4. Data Storytelling
- Analyzed monthly, regional, and product sales.
- Created visualizations.
- Prepared a business narrative.
- Suggested business recommendations.

### 5. Executive Reporting
- Calculated business KPIs.
- Created interactive Plotly charts.
- Exported chart images.
- Generated an executive PowerPoint report.

### 6. Production Architecture Review
- Reviewed the reporting application's architecture.
- Identified production-readiness gaps.
- Prepared a proposed architecture.
- Created a risk assessment and improvement roadmap.

### 7. Security Audit
- Built a static security scanning script.
- Checked selected source-code and configuration patterns.
- Categorized findings by severity.
- Generated CSV, JSON, and Markdown reports.

## How to Run

Each project has its own folder and dependencies.

1. Open the required project folder in VS Code.
2. Create and activate its virtual environment.
3. Install dependencies from its requirements file.
4. Run the relevant Python script.
5. Review generated files in its outputs folder.

## Important Notes
