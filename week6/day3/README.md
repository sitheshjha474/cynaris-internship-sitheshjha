# Week 6 - Apache Superset Dashboard

## Objective

Built an Apache Superset dashboard using the 100,000-row Indian retail sales dataset.

## Setup

- Apache Superset
- Docker
- PostgreSQL
- 100,000 retail sales records

## Dashboard Charts

1. Sales by Category - Bar Chart
2. Sales Trend Over Time - Line Chart
3. Sales by Payment Method - Pie Chart
4. Total Sales - Metric
5. State-wise Sales and Profit - Table

## Dataset

The `retail_sales` PostgreSQL table contains 100,000 retail sales records.
